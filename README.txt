FINANCIAL CALCULATOR 2.0 - IPHONE WEB APP

WHAT YOU GET
A free mobile-friendly calculator with all seven functions from your Python program.
It runs in Safari and other modern browsers; it does NOT need Python or Tkinter on iPhone.

TRY ON WINDOWS FIRST
Double-click index.html in the extracted folder. The calculator works locally.

TO USE ON IPHONE
These files must be published together on an HTTPS website. Merely copying index.html to the iPhone Files app does not create a Home Screen app.
One free route: create a GitHub repository, upload the five web files, then enable GitHub Pages in Settings > Pages, deploy from main branch/root. Wait for the published HTTPS link. (GitHub's interface and plan conditions can change.)
Alternatively use any static website host that supports HTTPS.

On iPhone: open the HTTPS link in Safari, tap Share, choose Add to Home Screen, then Add.
After first successful loading, the service worker caches the app for offline use.

FILES
index.html: complete mobile calculator (no backend required)
manifest.webmanifest: installable app metadata
service-worker.js: offline cache
icon-192.png and icon-512.png: app icons

IMPORTANT
This is a browser-based conversion of the Python calculator; calculations are implemented in JavaScript to run without a server. The program is not hosted by ChatGPT, so no public link exists until you publish it.
Currency selection changes labels only, not exchange rates.
Loan calculations assume fixed rates and full amortization; no taxes or fees.
